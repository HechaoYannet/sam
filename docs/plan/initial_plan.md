# 项目计划书：双流协同的原生多模态因果推理验证
**——基于跨模态JEPA (MM-JEPA) 的连续流形联合推断研究**

## 1. 核心愿景与理论重构：从“翻译”到“平权协同”

### 1.1 范式纠偏：视觉与符号的本体论平权
当前MLLM的失败在于将符号视为“统治者”，视觉视为“附庸”（视觉必须翻译成符号才能思考）。而纯视觉路线的局限在于缺乏逻辑锚点，容易在长程推理中发生“流形漂移”（幻觉）。
本项目提出 **“双流协同流形”（Dual-Stream Collaborative Manifold）** 理论：
-   **视觉流（高维/连续/具身）**：负责构建丰富的世界状态（State）和物理动力学（Dynamics）。
-   **符号流（低维/离散或连续化/逻辑）**：负责提供因果干预（Intervention）、逻辑约束（Constraints）和长程规划（Planning）。
-   **原生思考的本质**：推理不再是“生成下一个词”或“生成下一张图”，而是在统一的Latent Space中，**符号作为向量场（Vector Field）或能量约束，引导视觉表征沿着符合物理和逻辑规律的测地线（Geodesic）演化。**

### 1.2 核心研究假设 (H1)
> 在一个统一的连续表征空间中，如果将符号信息作为动力学演化的条件约束（而非自回归生成的终点），模型能够涌现出比纯视觉或纯符号更强大、且具备严格逻辑一致性的跨模态因果推断能力。

## 2. 极简架构设计：跨模态JEPA (MM-JEPA) 
*(适配8GB RTX 4060 Laptop)*

为了实现上述理论，我们摒弃传统的“图文交叉注意力”机制（这本质上还是翻译），设计一种在Latent Space直接进行**跨模态状态预测**的极简架构。

### 2.1 架构拓扑
```text
[视觉输入: 初始状态图] ──> [ViT-Tiny 编码器] ──> 视觉表征 Z_v(t) ──────┐
                                                                      │
[符号输入: 因果条件/规则] ──> [轻量MLP/Symbol Encoder] ──> 符号表征 Z_s ─┤
                                                                      ▼
                                                          [ 跨模态动力学预测器 ]
                                                                      │
                                                                      ▼
                                                           预测视觉表征 Z_v(t+1)_pred
                                                                      
[视觉输入: 真实结果图] ──> [EMA 目标编码器] ──> 真实视觉表征 Z_v(t+1)_target
                                                                      
Loss = || Z_v(t+1)_pred - Z_v(t+1)_target ||² + 符号一致性正则项
```

### 2.2 关键机制创新
1.  **符号作为控制信号（Symbol as Control）**：符号表征 $Z_s$ 不参与自回归生成，而是作为条件向量，通过FiLM（Feature-wise Linear Modulation）或简单的加法/拼接，直接调制视觉预测器的权重或偏置。这意味着**符号在“指挥”视觉状态的演化**。
2.  **双向因果对齐（Bidirectional Causal Alignment）**：
    -   *正向推断*：给定 $Z_v(t)$ 和 $Z_s$，预测 $Z_v(t+1)$。（例如：看到积木，加上符号“施加向左的力”，预测积木倒塌的视觉表征）。
    -   *反向归因*：给定 $Z_v(t)$ 和 $Z_v(t+1)$，预测导致该变化的符号表征 $Z_s$。（例如：看到积木从直立变成散落，推断出“受到了侧向撞击”的符号表征）。
3.  **内存极致优化**：
    -   ViT-Tiny (~5M参数) + 2层MLP符号编码器 (~1M参数)。
    -   目标编码器使用EMA（指数移动平均）冻结梯度，节省50%反向传播显存。
    -   全程 `bfloat16` + 梯度累积（Micro-batch=8, Accum=4）。

## 3. 数据集构建：CausalFlow-Synth-MM (多模态版)

为了验证视觉与符号的协同，数据集必须包含**强耦合的视觉状态变化与符号逻辑规则**，且规模控制在显存可承受范围内（约10,000组样本）。

### 3.1 数据生成管线 (基于Blender Physics + 程序化脚本)
每个样本包含一个三元组：$(I_{start}, S_{rule}, I_{end})$
-   **$I_{start}$ (初始视觉)**：3D场景的渲染图（如：不同材质、形状的物体在斜坡上）。
-   **$S_{rule}$ (符号条件)**：结构化的符号序列或自然语言短句（如：`[Mass:Heavy] [Force:Right] [Friction:Low]` 或 "重物体受向右的力，低摩擦"）。
-   **$I_{end}$ (结果视觉)**：物理引擎模拟后的状态图。

### 3.2 核心考察的跨模态因果类型
1.  **物理属性干预**：符号改变物体的隐含属性（如将“木头”改为“铁”），视觉预测其下落轨迹的改变。
2.  **空间逻辑约束**：符号描述拓扑关系（如“A在B内部，B移动”），视觉预测A的绝对空间位置变化。
3.  **反事实推断**：提供真实的 $I_{start}$ 和 $I_{end}$，但给出一个**错误的** $S_{rule}$（如“施加了向上的力”），要求模型在Latent Space中识别出符号与视觉演化轨迹的冲突（能量异常）。

## 4. 评估体系：多模态协同的定量与几何指标

除了常规的准确率，我们必须引入能衡量“视觉与符号是否在流形上真正融合”的指标。

### 4.1 定量指标矩阵
| 评估维度 | 具体指标 | 计算方式 | 成功基准 |
| :--- | :--- | :--- | :--- |
| **正向因果推断** | 跨模态状态预测误差 | $MSE(Z\_v(t+1)\_{pred}, Z\_v(t+1)\_{target})$ | 显著低于纯视觉JEPA基线 |
| **反向因果归因** | 符号规则Zero-shot召回率 | 给定视觉变化，Top-1预测出正确符号规则的比率 | > 60% |
| **逻辑一致性** | 反事实冲突检测率 | 模型能否准确识别出“错误的符号条件”与“视觉变化”不匹配 | > 75% |
| **长程推理** | 多步符号规划准确率 | 给定初始图和最终目标图，预测出正确的3步符号操作序列 | > 40% |

### 4.2 流形几何分析 (核心定性验证)
-   **符号引导的测地线平滑度**：在Latent Space中，固定初始视觉表征，连续改变符号表征（如力的大小从0渐变到10），观察预测的视觉表征轨迹是否形成一条平滑、连续的曲线。如果轨迹发生断裂或跳跃，说明符号未能有效约束视觉流形。
-   **跨模态同构性 (Isomorphism)**：使用RSA（Representational Similarity Analysis）分析视觉状态变化的距离矩阵与符号逻辑距离矩阵的同构程度。高度同构证明模型学到了统一的因果几何。

## 6. 风险与应对策略 (针对8G显存与理论验证)

1.  **风险：符号表征被视觉表征“淹没”（模态主导问题）**
    -   *应对*：在Loss中引入**模态对比正则项**，强制要求符号编码器输出的方差和范数与视觉编码器保持在同一量级；或者使用正交投影，确保符号信息提供的是视觉流形切空间上的独立方向。
2.  **风险：8G显存无法支撑双向预测（正向+反向）**
    -   *应对*：采用**课程学习（Curriculum Learning）**。前4周只训练正向预测（视觉+符号 -> 视觉），冻结符号编码器；后4周解冻，利用已学好的视觉动力学来训练反向归因。
3.  **风险：模型退化为“死记硬背”符号到视觉的映射，而非真正理解因果**
    -   *应对*：在测试集中引入**组合泛化（Compositional Generalization）** 样本。例如，训练集见过“红球受重力”和“蓝方块受弹力”，测试集要求预测“红方块受弹力”。如果模型具备原生因果推理能力，它能在流形上组合这些特征；如果只是死记硬背，准确率将暴跌。
