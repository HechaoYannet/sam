## 5. 关键发现

### 5.1 结构化类比是 v8 的核心贡献

+20.6pp E1 test_ood 的提升完全来自结构化类比数据。当模型被训练去预测"只改变一个属性"的类比时，它学会了更精确的流形向量运算。v7 在同一测试数据上的 64.4% 说明架构本身具备能力，但训练数据质量是瓶颈。

### 5.2 E2 关系同构接近天花板

RSA ρ = 0.997 意味着视觉位移向量和符号位移向量几乎完全对齐。模型在 256 维流形上学到了完美的跨模态关系同构。

### 5.3 解码器精度全面提升

所有属性解码精度均有改善（+0.3pp 到 +4.2pp），无任何属性出现退化。直和架构 + VICReg 协方差的组合被证明是稳健的。

### 5.4 连续颜色架构就绪但未激活

本训练运行使用离散颜色（渐进策略阶段 1）。ColorEncoder、RGB 回归头、颜色代数代码均已就位，等待后续的连续色相训练。L1 未见色相测试在此阶段预期不适用。
